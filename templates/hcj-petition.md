# High Court Petition (עתירה לבג״ץ)

A Hebrew skeleton for a petition to the Supreme Court sitting as the High Court of Justice, asking for an order nisi (צו על תנאי), filed without a lawyer, with a threshold checklist. Taught in [lesson 05.7](../lessons/module-05/lesson-07.md). The supporting affidavit (Form 2) uses the [affidavit template](affidavit.md).

> [!IMPORTANT]
> For use in your own name (or in the name of the amuta that is the petitioner) only. This is not legal advice — check current rules before filing, including the fee on [Current Numbers](../references/current-numbers.md) and the filing route for unrepresented petitioners, which you should confirm with the judiciary information centre (*3852) or the Supreme Court registry. Drafting petitions for others as an occupation or for payment is reserved to lawyers (Bar Association Law s. 20).

## How to use it

1. Run the forum test from lesson 05.7: not a First Schedule (or Fourth Schedule) matter, or excluded from it, or a remedy about regulations; no other court or tribunal can hear it.
2. Run the threshold checklist below. Fix every gap before drafting.
3. Write the remedies in the customary order-nisi wording ("לבוא וליתן טעם, אם יש בידם, מדוע לא…").
4. Give your personal details and an address for service in Israel (regs 2–3).
5. Print on one side of the page with margins of at least 5 cm (reg. 2).
6. Attach the affidavit (Form 2) or write it at the end (reg. 4), certified.
7. Fee: item 24 of the schedule to the Court Fees Regulations, or a fee-exemption request with an affidavit on assets and six months of income (reg. 14).
8. After filing, serve every document you file on every other party the same day (reg. 8א).

## The petition

```text
בבית המשפט העליון
בשבתו כבית משפט גבוה לצדק

בג"ץ ________ (יינתן בעת ההגשה)

העותר/ת:     [שם מלא], ת"ז [מספר]
              מען להמצאה: [כתובת בישראל]
              טל': [___]; דוא"ל: [___]
              (לא מיוצג/ת)

                                  – נ ג ד –

המשיבים:     1. [השר/ה / הממשלה / הרשות], באמצעות פרקליטות המדינה, מחלקת בג"צים, ירושלים
              2. [רשות נוספת הנוגעת בדבר]
              3. [מי שעלול להיפגע מקבלת העתירה, אם יש], [כתובת]

עתירה למתן צו על תנאי

זוהי עתירה למתן צו על תנאי המופנה אל המשיבים ומורה להם לבוא וליתן טעם, אם יש בידם:

א. מדוע לא [יבוטל / תבוטל] [ההחלטה / התקנה ___ מיום ___];
ב. מדוע לא [יפעל / יתקין / יחליט] המשיב 1 [הפעולה המבוקשת], בתוך [פרק זמן] או בתוך מועד אחר שיקבע בית המשפט הנכבד;
ג. [סעד נוסף, אם יש].

[אם יש בקשה לצו ביניים: בד בבד מוגשת בקשה נפרדת למתן צו ביניים, הנתמכת בתצהיר.]

ואלה נימוקי העתירה:

א. מבוא
1. [פסקה אחת: ההחלטה או המחדל, הפגם, הסעד.]

ב. הצדדים
2. העותר/ת [מי את/ה; עניינך האישי, או — לעותר ציבורי — מדוע העניין ציבורי וחשוב, ומדוע אין עותר מתאים ממך].
3. המשיב 1 [תפקידו וסמכותו, והחוק המסמיך].
4. המשיב [2/3] [עניינו בעתירה].

ג. העובדות
5. ביום [תאריך] [עובדה] (נספח 1).
6. [עובדה, תאריך, נספח.]

ד. מיצוי הליכים והיעדר שיהוי
7. ביום [תאריך] פנה/תה העותר/ת למשיב 1 בבקשה ל___ (נספח ___). ביום [תאריך] נשלחה תזכורת (נספח ___).
8. ביום [תאריך] נשלח מכתב התראה לפני הגשת עתירה (נספח ___). [התשובה מיום ___ מצורפת כנספח ___ / לא התקבלה תשובה.]
9. העתירה מוגשת [כ-___ ימים] לאחר [ההחלטה / התשובה האחרונה]. [המחדל נמשך עד היום.] העותר/ת פעל/ה בשקידה, ואין בהגשת העתירה כדי לפגוע באינטרס הסתמכות של איש.

ה. הסמכות — מדוע בית המשפט הגבוה לצדק
10. העניין אינו נמנה על התוספת הראשונה [או הרביעית] לחוק בתי משפט לעניינים מינהליים, התש"ס-2000 [לחלופין: הסעד העיקרי עניינו התקנת תקנות, המוחרג מסעיף 5(1) לחוק], ואין בית משפט או בית דין אחר המוסמך לדון בו. לכן הוא בסמכות בית המשפט הנכבד לפי סעיף 15(ג) ו-(ד)(2) לחוק-יסוד: השפיטה.

ו. הטיעון המשפטי
ו.1 [טענה — כותרת]
11. [הכלל + מקורו; העובדות; המסקנה.]
ו.2 [טענה — כותרת]
12. [___]

ז. הליכים נוספים
13. [לא הוגש הליך נוסף באותו עניין. / הוגש הליך ___.]

ח. אגרה
14. [האגרה שולמה לפי פרט 24 לתוספת לתקנות בתי המשפט (אגרות), התשס"ז-2007. / מוגשת בד בבד בקשה לפטור מאגרה לפי תקנה 14 לתקנות.]

ט. סוף דבר
15. לאור כל האמור, בית המשפט הנכבד מתבקש ליתן צו על תנאי כמבוקש בראש העתירה, ולאחר קבלת תשובת המשיבים להפכו לצו מוחלט, ולחייב את המשיבים בהוצאות העותר/ת.
16. עתירה זו נתמכת בתצהיר העותר/ת, המצורף לה (תקנה 4).

____________________
[שם מלא], העותר/ת
[תאריך]

רשימת נספחים:
נספח 1 — [תיאור] .................. עמ' ___
נספח 2 — [תיאור] .................. עמ' ___
נספח 3 — מכתב ההתראה ותשובת המשיב .. עמ' ___
```

## The supporting affidavit (Form 2)

Use [affidavit.md](affidavit.md). In paragraph 1 write: "אני העותר/ת בעתירה זו, ואני נותן/ת תצהיר זה בתמיכה לעתירה." Declare facts within your personal knowledge as true, and other facts as true to the best of your knowledge and belief, naming the source (reg. 4).

## Threshold checklist

| Threshold ground | My answer | Paragraph / exhibit |
|---|---|---|
| Forum: no other court or tribunal; not a First or Fourth Schedule matter (or excluded) | | |
| Exhaustion: written request, reminder, pre-petition letter, answer or silence | | |
| Delay: timeline from the decision to filing, with reasons for any gap | | |
| Standing: personal interest, or a public petitioner on a matter of public importance | | |
| Concrete decision or failure, and a specific remedy | | |
| All respondents, including anyone harmed if I win | | |
| Personal details and an Israeli address for service (regs 2–3) | | |
| Affidavit in Form 2, attached or at the end, certified (reg. 4) | | |
| Fee item 24, or exemption request (reg. 14) | | |
| Filing route and fee payment confirmed with *3852 or the registry (date: ___) | | |
| Service plan: every document, every party, same day (reg. 8א) | | |
