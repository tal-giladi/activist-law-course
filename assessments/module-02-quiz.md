# Module 2 quiz

This quiz checks whether you can research and write like a self-represented activist: find the current text of a law, find and check rulings, use secondary sources safely, build an argument, write a formal letter and prepare an affidavit. It has 10 scenario questions. The pass mark is 70%.

The questions describe realistic situations and ask what you would do. If you are unsure about a topic, revisit the lesson before you start.

## Revisit by topic

- Case numbers, the free judgments search and checking a ruling is still good law: [02.2 · Finding Rulings for Free](../lessons/module-02/lesson-02.md)
- Kol Zchut, Knesset Research papers and verifying secondary sources: [02.3 · Secondary Sources](../lessons/module-02/lesson-03.md)
- Issue, rule, application, conclusion and the element table: [02.4 · Building a Legal Argument](../lessons/module-02/lesson-04.md)

- Form, certification, cost and risks of an affidavit: [02.6 · Affidavits](../lessons/module-02/lesson-06.md)
