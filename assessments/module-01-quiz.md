# Module 1 quiz

This quiz checks whether you can use the map of Israeli law in realistic situations: where the line runs between acting for yourself and practising law, which rule wins, which forum hears a dispute, how to read a statute and how to use a ruling. It has 10 scenario questions; the pass mark is 70%. Each answer comes with a short explanation after you submit.
